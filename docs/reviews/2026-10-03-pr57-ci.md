# PR57 — correção do scan de dependências da API

Data: 03/10/2026. Base: `63e14fe959f7d61b1fa6bf2266f130c8c7887dfc`.

## Falha e resolução

O [job 111276951895 do run 37148396913](https://github.com/OWNERINC/portal_ownerinc/actions/runs/37148396913/job/111276951895)
falhou em **Scan API image**: Trivy encontrou dois HIGH em
`@fastify/busboy@3.2.0`, ambos com correção indicada em **3.2.1**:

- `CVE-2026-19481`: DoS por headers form-data construídos maliciosamente.
- `CVE-2026-19484`: DoS por boundary multipart excessivamente grande.

A árvore instalada confirmou `firebase-admin@14.2.0 → @fastify/busboy@3.2.0`.
O requisito do pai é `^3.0.0`, compatível com o patch. O registry confirmou
versão, URL e integridade de 3.2.1. `api/package-lock.json` passa a resolver
**3.2.1** com esses metadados; a comparação estrutural integral do lock com a
base identificou somente essa entrada alterada. `npm ci` reproduziu a resolução.

O comando direcionado `npm --prefix api update @fastify/busboy --package-lock-only
--ignore-scripts --no-audit --no-fund` selecionou inicialmente 3.2.2. Antes da
verificação final, a entrada foi ajustada à correção mínima solicitada, 3.2.1,
usando os metadados oficiais. A instalação limpa final e os checks abaixo foram
executados com 3.2.1.
